# To-Do List App 

A simple and cute pink to-do list web app built with HTML, CSS and JavaScript.

## Features

- Add new tasks (with the Add button or the Enter key)
- Mark tasks as completed (a line appears on the task)
- Delete tasks
- See how many tasks are still pending
- Responsive layout that works on mobile and desktop

## Tech Used

- **HTML** for the page structure
- **CSS** for the pink theme and layout
- **JavaScript** for adding, completing and deleting tasks

## Project Structure

index.html
style.css
script.js

## How to Run

1. Download or clone this repository.
2. Keep all three files in the same folder.
3. Open `index.html` in any browser.
